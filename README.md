# ميثاق المؤمن | الموقع الرسمي

الموقع التعريفي الرسمي لمشروع **ميثاق المؤمن**، مشروع تطبيق ديني شيعي باللغة العربية قيد التطوير، من تأسيس وابتكار وتطوير **حسين لؤي فرحان**.

## صفحات الموقع

- `index.html` — الصفحة الرئيسية: فكرة المشروع، مجالات العمل، منهج التطوير، وروابط التعريف.
- `founder.html` — صفحة المؤسس: حسين لؤي فرحان وعلاقته بالمشروع.
- `404.html` — صفحة مخصصة للروابط غير الموجودة.
- `style.css` — نظام التصميم والتجاوب مع أحجام الشاشات.
- `assets/mark.svg` — العلامة البصرية للموقع.
- `robots.txt` و `sitemap.xml` — ملفات إرشاد وفهرسة محركات البحث.

## النشر عبر GitHub Pages

1. افتح إعدادات المستودع `Settings`.
2. انتقل إلى `Pages`.
3. في `Build and deployment` اختر `Deploy from a branch`.
4. اختر الفرع `main` والمجلد `/(root)` ثم احفظ.
5. بعد اكتمال النشر، افتح رابط Pages الظاهر في صفحة الإعدادات.

## معلومات تقنية

- HTML وCSS فقط؛ لا توجد أطر عمل أو مكتبات JavaScript مطلوبة.
- الواجهة عربية من اليمين إلى اليسار ومتجاوبة مع الهاتف والحاسوب.
- توجد عناوين ووصف وبيانات منظمة وروابط أساسية لمحركات البحث.
- لا يتضمن الموقع ادعاءات عن عدد المستخدمين أو التقييمات أو تاريخ إطلاق غير معلن.

## ملاحظة عن حالة المشروع

الموقع يعرّف بالمشروع ورؤيته. تطبيق ميثاق المؤمن نفسه ما زال قيد التطوير والمراجعة، والمجالات المذكورة في الموقع تعبّر عن اتجاه العمل وليست إقراراً بأن كل الخصائص منشورة أو متاحة حالياً.
