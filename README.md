# ميثاق المؤمن | الموقع الرسمي

صفحة تعريف وتسويق لمشروع تطبيق **ميثاق المؤمن**، وهو تطبيق ديني شيعي باللغة العربية لنظام Android، قيد التطوير.

## صفحات وملفات الموقع
- \`index.html\` — صفحة المشروع الرئيسية.
- \`founder.html\` — التعريف بمؤسس المشروع، حسين لؤي فرحان.
- \`style.css\` — نظام التصميم المتجاوب.
- \`assets/home-preview.webp\` — تصوّر بصري لواجهة التطبيق، وليس لقطة إصدار منشور.
- \`assets/mark.svg\` — أيقونة تبويب المتصفح الحالية.
- \`404.html\` — صفحة الروابط غير الموجودة.
- \`robots.txt\` و\`sitemap.xml\` — ملفات الفهرسة.

## النشر
يُنشر الموقع عبر GitHub Pages من الفرع \`main\` والمجلد الجذر \`/(root)\`.

## ملاحظات
- الواجهة عربية RTL ومهيأة للهاتف أولاً.
- لا توجد روابط تنزيل أو تقييمات أو أرقام مستخدمين غير مثبتة.
- زر المتابعة يفتح مستودع تطوير تطبيق Android.
- صورة الواجهة موسومة بوضوح على أنها تصوّر بصري، وليست دليلاً على اكتمال التطبيق.
